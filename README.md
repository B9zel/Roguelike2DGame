
# Жанр игры: Рогалик, Метроидвания

---
---



## **Краткое введение:**

- ### Цель:
	- Изучить мир игры попутно победить боссов для открытия навыков и получения артифактов боссов
	
- ### Процесс игры:

	**Если персонаж умрет, то часть золота исчезнит**

1. Игрок попадает на стартовую локацию, откуда он может пойти куда угодно, на пути ему будут встречаться обитатели данной локации(в зависимости от того в какаой локации находится игрок).
	- 1.1 На пути игроку будут встечаться фрагменты карты, собирая, которые игроку будет легче ориентироваться по миру.
	- 1.2 Также изредко будут попадаться магические свитки, которые будут увеличивать количества здоровья, маны или скорость атаки, но для того чтобы их активировать нужн пойти к мастеру, который сможет расшифровать их и дать на выбор игроку способности за золото
	- 1.3 Игрок может сражаться с врагами, чтобы добыть золото
	- 1.4 Во время прохождения локации может встретиться кузнец, который можнет улучшить оружие(урон) за золото




	
- ### Системы:
	- Сохранение
	- Прогрессии
	- Нахождение артифактов
	- Собирание карты по кускам
	- Исполтзование навыков, амулетов/артифактов
	- Анимаций

- ### Механики:
	- Отрываются по мере прохождения игры:
		- Рывок(Dash)
		- Цепляться к стенам
		- При использование амулетов/артифактов тртаиться мана
	- Присутствуют всегда:
		- Передвижение
		- Двойной прыжок
		- Умирая игрок теряет часть золота		- Боевка
	

## **Монстры:**

1. Скелет
	- 1.1 Атакует вблизи
2. Слаймы
	- 2.2 Атакует вблизи

## **Боссы:**
1. Король скелетов					
	- 1.1 Атакует вблизи
	- 1.2 Спавнит скеле
	
2. Король слаймов					
	- 2.1 Атакует вблизи
	- 2.2 Спавнит слаймов
## **Игровой персонаж**
- Имеет одно оружие на всю игру
- Можно улучшить урон от меча

## **Амулеты/артифакты**
- Их находит игрок во время игры
- Можно использовать только 2 амулета/артифакта
